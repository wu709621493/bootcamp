# Privacy Notice

This repository hosts instructional materials for the Caltech Introduction to Programming for the Biological Sciences Bootcamp. It does not intentionally collect personal data, run analytics, or include tracking code.

- **Local content only.** All notebooks, scripts, and datasets are stored in the repository. They operate on user-provided inputs locally without sending data to external services.
- **No telemetry.** The codebase does not embed telemetry, ad trackers, or third-party analytics libraries.
- **Data you add stays yours.** If you clone or fork the repository and add personal data (e.g., analysis outputs or custom datasets), you are responsible for safeguarding and removing that data.
- **Third-party tools.** When running exercises that depend on external packages, refer to those packages' privacy policies for their handling of logs or network requests.

For questions or privacy-related concerns, contact the bootcamp maintainers.
