# Bootcamp feedback

## Highlights
- Clear progression from fundamentals to applied biological examples helps learners connect programming to research needs.
- Short exercises with immediate checks make it easy to validate understanding before moving on.
- The mix of notebooks and plain Python modules supports both interactive exploration and production-style scripting.

## Opportunities to improve
- Add a short "why this matters" paragraph at the start of each module to anchor motivation, especially for students new to programming.
- Expand the troubleshooting section with common error messages (e.g., import errors, package version mismatches) and quick fixes.
- Include a lightweight style guide (naming, docstrings, plotting defaults) to make collaborative work more consistent across cohorts.

## Tooling and environment
- Provide a prebuilt environment file (e.g., `environment.yml` or `requirements.txt`) aligned to tested versions to reduce setup friction.
- Incorporate `pytest -q` as a standard pre-submission check so learners get early feedback on correctness.
- Offer guidance on using `nbstripout` or similar tools to keep notebooks clean in version control.

## Data and ethics
- Continue highlighting data licensing and attribution; adding a one-page overview on responsible data use would reinforce good habits.
- Encourage the use of synthetic or anonymized datasets for practice to minimize exposure of sensitive information.
- Remind learners to document data provenance in README files alongside analysis scripts.
