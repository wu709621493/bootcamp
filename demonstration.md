# Demonstration

A demonstration is a concise, observable proof that something works as intended.

## Purpose

- Make abstract claims concrete.
- Show expected inputs, behavior, and outputs.
- Build trust by reducing ambiguity.

## Minimal demonstration checklist

1. **State the goal** in one sentence.
2. **Show setup** (data, environment, or assumptions).
3. **Execute the core steps** in order.
4. **Present the result** clearly.
5. **Note limitations** and possible next checks.

## Example template

- **Goal:** Verify that a function returns the correct value for known test cases.
- **Setup:** Define three representative inputs.
- **Steps:** Run the function on each input.
- **Result:** Compare actual vs expected outputs.
- **Limitations:** This does not benchmark performance.

In short: if someone can reproduce your steps and see the same result, your demonstration is effective.
