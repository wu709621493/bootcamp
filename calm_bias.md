# Calm Bias

**Calm bias** is the tendency to favor emotionally steady, low-drama interpretations and actions when facing uncertainty.

## Core idea

When signals are noisy, calm bias nudges people to choose responses that:

- reduce avoidable escalation,
- preserve optionality,
- and keep communication clear.

## Practical use

Calm bias can be useful in decision-making when paired with evidence checks:

1. Name the risk without amplifying it.
2. Choose the smallest reversible step.
3. Set a short review window.
4. Escalate only if new data justifies it.

## Caution

If overused, calm bias can become underreaction. Pair calmness with explicit thresholds so important threats are not ignored.
