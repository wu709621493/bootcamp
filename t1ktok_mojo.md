# T1kToK mojo

A compact playbook for short-form video momentum:

1. **Hook in 1 second** with movement, surprise, or a bold claim.
2. **Keep a single idea** per clip so viewers never feel lost.
3. **Use pattern breaks** every 2–3 seconds (cuts, zooms, captions, angle shifts).
4. **Design for mute first** with large on-screen text and visual storytelling.
5. **End with a loop** so the last frame naturally connects to the first.
6. **Post consistently** and iterate from retention data, not guesses.

Mojo = clarity + rhythm + repeatable experimentation.
