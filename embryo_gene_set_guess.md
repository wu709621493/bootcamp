# Educated guess: first gene set expressed in an embryo

A broadly accepted educated guess is that the **earliest robust embryonic gene expression program** is the **zygotic genome activation (ZGA) set**, often called the **maternal-to-zygotic transition (MZT) genes**.

In many animals, the embryo initially uses **maternally deposited mRNAs/proteins**; then the first newly transcribed embryonic genes are typically:

1. **Genome activation factors** (transcription/chromatin regulators)
2. **Cell-cycle and basic housekeeping genes**
3. **Early patterning regulators** (species-specific, e.g., axis/specification genes)

So if one “gene set” is required: **minor ZGA genes (followed by major ZGA genes) during MZT** is the best concise answer.
