# Memo note

A good memo keeps the reader oriented even when it is read weeks later. Start with a crisp purpose line and define the decision or question you want answered. If background is needed, keep it lean and link to source documents instead of repeating them. Summaries travel farther than attachments.

List concrete recommendations up front, each tied to an owner and deadline. A timeline turns suggestions into commitments. When the memo must surface risks, separate the certainties from assumptions and name the indicators that would cause the plan to change.

Close every memo with next steps and a single point of contact. This prevents diffusion of responsibility and makes it obvious who will track replies. A memo is a living artifact; version and date it so updates can be traced without confusion.
