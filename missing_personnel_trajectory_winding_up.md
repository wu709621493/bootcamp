# Missing personnel trajectory winding up

## Premise

When someone is missing from a team, the work still moves, but the path the work takes curls inward. The trajectory is no longer straight-line execution; it is a spiral of checks, handoffs, and memory retrievals that gradually winds up toward a stable orbit. This document captures that winding-up motion, the way a system adjusts and re-anchors itself after a crucial person disappears.

## The trajectory

### 1. Initial drift

The first hours feel deceptively quiet. Tasks continue with momentum that was already stored in the system. People assume the missing person will return before anything snaps. This is a coasting phase, where friction is low and the direction is still inherited from the last known state.

### 2. Recognition of missing mass

Soon, interactions that used to be routine begin to slow. Questions arise that no one can answer quickly. The system detects a missing mass, an unfilled role that used to provide gravity. Work starts to widen its arc, drifting farther from the intended line.

### 3. Search and substitution

The team begins to search for substitutes—documentation, old emails, shadow owners, institutional memory. Each substitution is a temporary vector, not a permanent direction. The trajectory winds up, drawing smaller circles around the problem, attempting to create a new center.

### 4. Stabilization

A new anchor emerges: a person who learns the missing context, or a documented process that redistributes the knowledge. The trajectory tightens and the spirals become closer, indicating the system has found a new equilibrium.

### 5. Residual echo

Even when the system stabilizes, there is a residual echo. The team has rewritten its path, but the original person’s impact remains as a faint offset. The winding up is complete, but the memory of the drift persists.

## Signals to watch

- Increasing number of “Does anyone know…” messages.
- Tasks that ping-pong between multiple owners.
- Decisions deferred until “we can confirm.”
- Sudden demand for archaeology—old notes, builds, or databases.

## Practices to soften the winding

- Create a redundancy map for each role.
- Practice rotating ownership before it is needed.
- Maintain decision logs with reasons, not just outcomes.
- Keep a short, current glossary of domain concepts.

## Closing note

The winding-up trajectory is not failure. It is a system preserving forward motion while it replaces missing gravitational pull. Recognizing the stages makes it easier to shorten the spiral and return to a stable path.
