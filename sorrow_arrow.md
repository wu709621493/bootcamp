# Sorrow, Arrow

Sorrow stands like a half-formed letter: S ( ) rrow,
parentheses catching quiet breaths the mouth cannot hold.

An arrow remembers the draw before it flies,
a suspended note that trembles between loss and aim.

I notch both feelings on the same string—
one feathered with regret, the other with resolve—
and listen to their fletching whisper in the wind.

When the bow hums, the world splits gently:
toward the ache that circles back, toward the path that opens.

Either way, the motion is true; either way, the heart moves.
