# Conscience Module

A **conscience module** is a lightweight decision layer that asks, before action: 

1. **Is it true?** (factual integrity)
2. **Is it fair?** (impact across people, especially least-protected groups)
3. **Is it reversible?** (can we safely roll back if wrong)
4. **Is it owned?** (clear accountability for outcomes)

## Purpose

Use this module to reduce avoidable harm while preserving execution speed. It is not a veto machine; it is a short preflight check.

## Minimal workflow (90 seconds)

- **Frame**: State the decision in one sentence.
- **Check facts**: List what is known vs assumed.
- **Map impact**: Who benefits, who bears risk, who is unheard?
- **Set guardrails**: Define stop conditions and rollback path.
- **Assign owner**: Name who monitors outcomes and reports back.

## Trigger thresholds

Run the conscience module when any of the following is true:

- The decision affects safety, health, rights, or privacy.
- Uncertainty is high and effects are hard to reverse.
- Incentives could reward short-term gains over long-term trust.
- A stakeholder group is absent from the discussion.

## Output template

```text

Evidence quality:
Main beneficiaries:
Main risk-bearers:

```

## Practical note

A small conscience check performed consistently is more effective than a perfect ethics review performed rarely.
